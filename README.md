# Electricity Billing Calculator

**Python Programming Project | Python · Google Colab · Conditional Logic · Algorithm Design**

## Project Overview

โปรเจกต์นี้เป็นการพัฒนาโปรแกรมคำนวณค่าไฟฟ้าด้วย Python บน Google Colab
โดยรับจำนวนหน่วยไฟฟ้าที่ใช้จากผู้ใช้งาน และคำนวณค่าใช้จ่ายตามโครงสร้างอัตราค่าไฟแบบขั้นบันได

โปรแกรมคำนวณค่าไฟฟ้าฐาน ค่าบริการรายเดือน ค่า Ft ภาษีมูลค่าเพิ่ม (VAT)
และสรุปยอดค่าไฟฟ้ารวมที่ต้องชำระ

## Key Features

- รับจำนวนหน่วยไฟฟ้าจากผู้ใช้งาน
- คำนวณค่าไฟแบบ Progressive Rate
- รองรับอัตราค่าไฟหลายช่วงตามจำนวนหน่วย
- คำนวณค่าบริการรายเดือน
- คำนวณค่า Ft ตามจำนวนหน่วยที่ใช้
- คำนวณ VAT 7%
- แสดงรายละเอียดค่าใช้จ่ายแต่ละส่วนและยอดรวมสุทธิ

## Technologies Used

- Python 3
- Google Colab
- Jupyter Notebook
- Conditional Logic
- Functions
- Arithmetic Operations

## Calculation Logic

โปรแกรมแบ่งการคำนวณค่าไฟฟ้าตามจำนวนหน่วยออกเป็น 3 ช่วง

- 1–150 หน่วย
- 151–400 หน่วย
- มากกว่า 400 หน่วย

จากนั้นนำค่าไฟฟ้าตามหน่วยมารวมกับค่าบริการรายเดือน
ค่า Ft และ VAT เพื่อคำนวณยอดค่าไฟฟ้าสุทธิ

## System Workflow

1. ผู้ใช้งานกรอกจำนวนหน่วยไฟฟ้าที่ใช้
2. โปรแกรมตรวจสอบช่วงของจำนวนหน่วยด้วย Conditional Logic
3. คำนวณค่าไฟฟ้าตามอัตราของแต่ละช่วง
4. รวมค่าบริการรายเดือน
5. คำนวณค่า Ft
6. คำนวณยอดก่อนภาษี
7. คำนวณ VAT 7%
8. แสดงรายละเอียดและยอดค่าไฟฟ้ารวม

## Example Output

ตัวอย่างการใช้ไฟฟ้า **285 หน่วย**

```text
ค่าบริการรายเดือน: 24.62 บาท

ค่าไฟฟ้าก่อน VAT: 1186.47 บาท
VAT 7%: 83.05 บาท
ค่าไฟฟ้ารวมทั้งหมด: 1269.53 บาท
```

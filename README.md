# Electricity Billing Calculator

**Python Programming | Google Colab · Conditional Logic · Functions · Arithmetic Operations**

โปรเจกต์เขียนโปรแกรมคำนวณค่าไฟฟ้าด้วย Python โดยรับจำนวนหน่วยไฟฟ้าที่ใช้จากผู้ใช้งาน แล้วคำนวณค่าไฟตามช่วงของจำนวนหน่วย รวมถึงค่าบริการ ค่า Ft และภาษีมูลค่าเพิ่ม (VAT) ก่อนแสดงยอดค่าไฟฟ้ารวม

## Project Overview

โปรแกรมนี้พัฒนาด้วย Python สำหรับคำนวณค่าไฟฟ้าจากจำนวนหน่วยที่ผู้ใช้งานกรอก โดยกำหนดอัตราค่าไฟแตกต่างกันตามช่วงของการใช้ไฟฟ้า

การคำนวณแบ่งออกเป็น 3 ช่วง ได้แก่ ไม่เกิน 150 หน่วย, 151–400 หน่วย และมากกว่า 400 หน่วย โดยใช้ If-Else ในการตรวจสอบจำนวนหน่วยและคำนวณค่าไฟของแต่ละช่วง

หลังจากคำนวณค่าไฟตามหน่วยแล้ว โปรแกรมจะรวมค่าบริการรายเดือน คำนวณค่า Ft ตามจำนวนหน่วยที่ใช้ และคิด VAT 7% เพื่อหาค่าไฟฟ้ารวมที่ต้องชำระ

## Electricity Rates

อัตราที่กำหนดไว้ในโปรแกรมมีดังนี้

| Electricity Usage | Rate |
|---|---:|
| 1–150 units | 3.2484 บาท/หน่วย |
| 151–400 units | 4.2218 บาท/หน่วย |
| More than 400 units | 4.4217 บาท/หน่วย |

ค่าใช้จ่ายเพิ่มเติมที่ใช้ในการคำนวณ

- **Monthly Service Charge:** 24.62 บาท
- **Ft:** 0.3672 บาท/หน่วย
- **VAT:** 7%

## Calculation Logic

โปรแกรมตรวจสอบจำนวนหน่วยไฟฟ้าที่ผู้ใช้งานกรอกและคำนวณตามเงื่อนไขดังนี้

- หากใช้ไฟไม่เกิน 150 หน่วย คำนวณด้วยอัตราของช่วงแรก
- หากใช้ไฟ 151–400 หน่วย คิด 150 หน่วยแรกด้วยอัตราช่วงแรก และหน่วยที่เหลือด้วยอัตราช่วงที่สอง
- หากใช้ไฟมากกว่า 400 หน่วย คิด 150 หน่วยแรกด้วยอัตราช่วงแรก 250 หน่วยถัดไปด้วยอัตราช่วงที่สอง และหน่วยที่เกิน 400 ด้วยอัตราช่วงที่สาม

จากนั้นนำค่าไฟตามหน่วยมารวมกับค่าบริการรายเดือนเป็นค่าไฟฟ้าฐาน แล้วคำนวณค่า Ft ตามจำนวนหน่วยที่ใช้ ก่อนนำยอดรวมไปคิด VAT 7%

## Program Workflow

1. รับจำนวนหน่วยไฟฟ้าที่ใช้จากผู้ใช้งาน
2. ตรวจสอบช่วงของจำนวนหน่วยด้วย If-Else
3. คำนวณค่าไฟตามอัตราของแต่ละช่วง
4. รวมค่าบริการรายเดือน
5. คำนวณค่า Ft ตามจำนวนหน่วย
6. คำนวณยอดก่อน VAT
7. คำนวณ VAT 7%
8. แสดงรายละเอียดค่าใช้จ่ายและยอดรวม
